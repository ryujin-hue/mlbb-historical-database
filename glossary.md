# MLBB Glossary — English / Indonesian / Malaysian Terms & Slang

Compiled glossary of in-game and community terms used across the Land of Dawn scene. Text-only records are image-exempt per the database spec. Definitions reflect standard community usage documented across the sources mined in this project (ONE Esports guides, official patch terminology, mlbbhub data labels); this file is a reference lexicon, not a claims register — no per-term source rows are attached.

## Core Gameplay (EN)

| Term | Meaning |
|---|---|
| MOBA | Multiplayer Online Battle Arena; 5v5 genre MLBB defined on mobile |
| Lane | Fixed path across the map: Gold lane, EXP lane, Mid lane |
| Sidelane | Either outer lane (Gold or EXP); a "sidelaner" splits from the mid/action |
| Roam | The support-style role that moves between lanes; equipped with Roaming Footwear + blessing |
| Jungler | The Retribution-holder who farms jungle camps and controls Turtle/Lord |
| Hyper carry | Team comp funnelling resources into one late-game damage dealer |
| Farm / Gold | Creep and jungle income; the economy tracked in `systems.csv` (Economy rows) |
| Wave / Minion wave | Periodic creep line; wave management is core macro |
| Push / Siege | Applying pressure to turrets; siege damage rules have dated changes (1.5.88–1.7.20) |
| Backdoor | Attacking turrets/base while enemy team is alive and away |
| Split push | Pressuring a sidelane while the team postures elsewhere |
| Zone control | Denying area with skill kits (e.g. Zhuxin's Soul Snare post-2.1.40) |
| Crowd control (CC) | Stuns, freezes, pulls, suppression |
| Blink / Dash / Charge | Movement-skill categories |
| Buff / Debuff | Stat or status modifiers; also the two jungle buffs (orange/purple) spawning at 0:30/90s |
| Objectives | Turtle, Lord, turrets, buffs — the macro scoreboard |
| Lord | Major neutral boss; spawns 8:00, evolves at 18:00 (S23 rules) |
| Turtle | Early objective; first spawn 2:00, 2-minute respawn cycle; Healing Turtle variant (2026 map) |
| Lithowanderer | Small jungle golem (0:45 spawn) granting movement/defense edge |
| Scavenger Crab | River crab granting chase utility |
| Retribution | Jungle spell required for jungle items; upgrades into Bloody/Flame/Ice Retribution |
| Flicker | The universal escape/engage spell (120s cooldown) |
| Execute | Finisher spell; compare item-based executes like Sky Piercer's Lethality |
| Savage | Killing the entire enemy team in one streak |
| Maniac | Triple-kill-plus announcement tier below Savage |
| First Blood | First kill of the match |
| MVP | Best-scoring player of a match |
| GG / GGWP | "Good game (well played)" |
| AFK | Away from keyboard; penalized via Credit Score |
| Smurf | Experienced player on a low-rank alt account |
| Meta | Most effective tactics available; the subject of `meta_history.md` |
| Power creep | New content raising the power ceiling over time |
| Buff / Nerf / Adjust / Rework / Revamp | Patch change taxonomy used in `hero_changes.csv` / `item_changes.csv` |
| Advanced Server | Test realm where patches land before live servers |
| Mythic / Mythical Honor / Mythical Immortal | Top ranked tiers (star bands 24/49/99/100+ per `systems.csv`) |
| War Season / Starlight | Ranked season structure / the monthly battle-pass style subscription |
| Collector / Legend / Epic | Premium skin tiers (draw and direct-purchase economies documented in `business.csv`) |

## Indonesian (ID) — the game's largest community

| Term | Meaning |
|---|---|
| Mabar | "Main bareng" — playing together as a squad |
| Gas / Gaskan | "Go / let's go" — start the match or push |
| Push rank | Grinding ranked stars |
| Jagoan | One's best/main hero ("main jagoan") |
| Asal jerk | Careless aggressive play ("asal jerking" skills) |
| Buang ult | Wasting the ultimate |
| Nekat | Recklessly committing |
| Jalan / Push | Lane / push (same as EN) |
| Feeder | Repeatedly dying to feed the enemy |
| Cari aman | Playing safe ("looking for safety") |
| Kayang | Being carried by a stronger teammate |
| Noob / Pro | Skill labels (universal) |
| Baper | Overemotional play/attitude after a loss |
| Mager | "Males gerak" — refusing to move/rotate (lazy play) |
| Turu | Sleep; "turu dulu" = leaving to sleep |
| One team / mabar squad | Fixed five-stack |
| Maling | "Thief" — stealing farm/kills/objectives |
| camping (numpang lewat) | Ambushing a lane repeatedly |
| Nuke | Burst damage combo |
| War | Teamfight ("gaskun war!") |
| Engkoh | Veterans' slang for strategist/shotcaller (older community usage) |
| Member | Squadmate in a mabar lobby |
| Solo rank / Solo player | Queueing ranked alone (high-variance reputation) |
| KDB | "Kalau diban, biasa" — ban-tier complaint meme (hero always banned) |
| Gacha | Draw events (Collector/Lucky Spin economies) |
| Top up | Buying diamonds |

## Pro-Scene & Esports Terms

| Term | Meaning |
|---|---|
| MPL | Mobile Legends: Bang Bang Professional League (PH/ID/MY/SG/KH/BR/LATAM/MENA) |
| MDL | Mobile Legends Development League (PH/ID) |
| MSC | Mid-Season Cup (Southeast Asia Cup 2017–2023; Esports World Cup 2024–) |
| M-Series | The world championship line (M1 2019 → M7 2026 → M8 2027 Türkiye) |
| MWI | MLBB Women's Invitational (EWC program) |
| FMVP | Finals Most Valuable Player (Ourа, KarlTzy, Oheb, Bennyqt, FlapTzy, Kelra, Light) |
| Bo3/Bo5/Bo7 | Best-of series lengths used across the circuit |
| Swiss stage | M6's group format (verified in mseries.csv format notes) |
| Wildcard | Pre-main-event qualification stage (M5 Malaysia, M8 Thailand) |
| Patch freeze | Locked patch version during international events |
| Franchise | MPL model with fixed slots (MPL ID S4: $1M fee) |
| Draft / Pick-Ban | Ban-pick phase; 10-ban Mythic+ since ~2024, esports 3rd ban since ~2019 |
| Flex pick | Hero pickable into multiple roles to hide strategy |
| Counter pick | Late pick answering the enemy lane |
| Shotcaller | In-game strategist |
| Rotate | Moving as a unit between objectives/lanes |
| Tempo | dictating the match pace through objective timings |
| Snowball | Converting early leads into unstoppable pressure (taxed by income reworks) |
| Throw | Losing a won game through mistakes |
| Comeback | Reversing a lost position (economy comeback mechanics in `systems.csv`) |
| Credit Score | 0–100 behaviour score gating ranked play |
| Two-Step Verification | Account security (mandatory post-2020 map-hack wave, patch 1.4.86) |
